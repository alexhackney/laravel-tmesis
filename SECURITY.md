# Security policy

Please report vulnerabilities privately to **alex@alexhackney.com**, or through GitHub's
"Report a vulnerability" form on this repository. Do not open a public issue for a
security problem.

Include the package version, what you expected, what happened, and a minimal way to
reproduce it. We aim to acknowledge a report within three working days.

Only the latest release line receives security fixes.

Webhook secrets, admin tokens and publish keys are credentials: never paste them into
an issue, a log or a report.
